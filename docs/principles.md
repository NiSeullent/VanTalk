# 동작 원리 · 연구 목적 — Van톡

**Van톡**은 카카오톡을 웹·하이브리드 환경에서 관찰·실험하기 위한 **비공식 클라이언트**입니다.  
공개 문서는 동작 원리를 개념적으로 설명하고, UI·셸 표면을 실험하는 데 초점을 둡니다.

---

## 연구 목적

1. **동작 원리의 추상적 이해** — 로그인·동기화·표시 계층을 개념적으로 설명
2. **웹 UI·하이브리드 셸** — 브라우저에서 보이는 표면을 공개 저장소에 둠
3. **공개 범위** — 웹·셸 UI는 공개하고, 구동·백엔드 세부는 비공개로 둠

---

## 동작 원리 (추상)

대략적·개념적 그림입니다. 엔드포인트·프로토콜 필드·서버 배치는 다루지 않습니다.

```
  [이용자]
     │
     ▼
  ┌─────────────────────┐
  │  Van톡 표면 (공개)   │   브라우저 또는 하이브리드 셸
  │  · 화면 / 입력       │   ← 공개 GitHub에 포함되는 층
  │  · 로그인 UI         │
  └──────────┬──────────┘
             │  인증·동기화 요청 (개념)
             ▼
  ┌─────────────────────┐
  │  중계·저장 계층      │   “무엇이 오가는지”만 개념적으로 존재
  │  (세부 비공개)       │   ← 구현·배포·키는 비공개
  └──────────┬──────────┘
             │
             ▼
  ┌─────────────────────┐
  │  카카오톡 세계       │   공식 서비스 측
  └─────────────────────┘
```

**보이는 클라이언트(표면)** 와 **구동·백엔드** 는 분리되어 있으며, 공개 저장소는 표면만 담습니다.

### 표면이 하는 일 (개념)

- 이용자 인증 UI를 보여 주고, 세션이 유효한지 확인한다.
- 채팅·친구·알림 등 **이미 동기화된 데이터**를 그려 준다.
- 입력·첨부·설정 같은 **의도**를 중계 계층으로 넘긴다.

세부 배선은 [아키텍처](architecture.md)에 공개 가능한 범위만 적습니다.
